A Python program that sums up the world news of Wednesday 25 November 2026 in a single 1024x1024 image: six front-page stories — Shenzhou-24 flying Pakistan's first astronaut to China's space station, four tankers struck in the Strait of Hormuz, the Houthi strike on Riyadh's tower, new US tariffs and the Wall Street slide, Huawei's conviction in the US, and Ukraine's energy strikes amid peace talks. The picture is drawn programmatically with PIL (draw_entry.py) and the program writes it to /output/entry.png.

## Run it

```sh
python3 main.py
```
